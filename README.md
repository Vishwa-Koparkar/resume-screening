# Resume Screening and Job Recommendation System using LLMs

NLP Lab Mini Project

## What it does
**Tab 1 - For Candidates** (upload one resume, get job recommendations)
1. Extracted details: name, email, phone, GitHub/LinkedIn links, education, CGPA, years of experience and skills found with NLP, plus the job category predicted by the LLM
2. Resume sections (collapsed by default): splits the resume into Summary, Education, Experience, Projects, Skills
3. Resume summary (collapsed by default): an abstractive summary and key highlights from the LLM, and the 3 most important sentences picked by NLP (extractive summarization)
4. Top 5 recommended jobs: the LLM compares the resume with all 44 jobs and gives a match score and a reason. Matched and missing skills are found with NLP skill matching
5. Check match for your own job: enter any job description and see the match score, matched skills and skills to learn
6. AI resume feedback: strengths, improvement suggestions and likely interview questions generated by the LLM

**Tab 2 - For Recruiters** (upload many resumes, screen them for one job)
- Pick a job and upload resumes. The LLM scores each resume against the job, and the resumes are ranked and marked shortlisted or rejected.

## How to run
1. Get a free Gemini API key from https://aistudio.google.com/apikey
2. Install and run:
```
pip install -r requirements.txt
streamlit run app.py
```
3. Paste the API key in the sidebar. (Or set it once in the terminal: `export GEMINI_API_KEY=your_key`)

## Files
- `app.py` - Streamlit web app
- `llm.py` - prompts and calls to the Gemini LLM
- `nlp_utils.py` - text cleaning, skill extraction, contact/education/experience extraction, section splitting, summarization
- `data/jobs.csv` - 44 job descriptions
- `data/skills.txt` - list of skills
- `data/sample_resumes/` - sample resumes for testing

## NLP techniques used
**Classic NLP (NLTK and regular expressions)**
- Text preprocessing: lowercasing, removing URLs, emails and special characters
- Tokenization (word and sentence): NLTK `word_tokenize`, `sent_tokenize`
- Stopword removal: NLTK stopword list
- Lemmatization: NLTK `WordNetLemmatizer`
- Information extraction: regular expressions for email, phone, links, education and years of experience (date ranges are merged so overlapping jobs are not counted twice)
- Skill extraction: keyword matching against a skills list, with aliases (e.g. "ML" = "machine learning"). Skills that a job description only calls "a plus" or "preferred" are not counted as required
- Section segmentation: rule-based detection of resume headings
- Extractive summarization: sentences scored by word frequency

**Large Language Model (Gemini)**
- Zero-shot text classification: predicts the resume category from 25 categories
- Semantic matching: compares the meaning of the resume and job descriptions, not just the words
- Job recommendation and resume screening: match score and a reason (matched and missing skills come from NLP skill matching)
- Text generation: resume feedback and interview questions
- Prompt engineering: each task has a prompt with a role, instructions and a fixed JSON output format
- Structured output: the LLM returns JSON, so the app can read the answer reliably

## Why an LLM instead of TF-IDF and cosine similarity
TF-IDF only counts matching words. It cannot tell that "ML" and "machine learning" mean the same thing, or that a
PyTorch developer is a good fit for a TensorFlow job. The LLM understands meaning and context, and it can also
explain its score in plain English.

## Limitations
- Needs internet and an API key; the free tier has a limit on requests per minute
- LLM scores can change slightly between runs and the LLM can make mistakes
- Skill matching only knows the skills in `data/skills.txt` and their listed aliases
- LLM calls are retried up to 3 times, but a very large batch can still hit the free-tier rate limit
- Resume text is sent to Google's servers

## Future scope
- Run an open-source LLM locally (e.g. Llama with Ollama) so no data leaves the computer
- Use embeddings and a vector database to search thousands of jobs quickly
- Fine-tune a model on a labelled resume dataset
